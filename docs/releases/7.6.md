# LUMEN 7.6

- Browser preserves the last readable page when navigation fails, reports HTTP
  errors, and retries blank first pages with a simplified layout.
- On-device rendering preserves more HTML, inline styles, image dimensions and
  responsive sources. CSS gradients support multiple stops and transparency.
- JavaScript adds DOM node insertion and removal, bubbling events, URL and
  URLSearchParams, and bounded same-origin XMLHttpRequest and Fetch responses.
- Reader shows 20 words on each side of the highlighted mention when available,
  with ellipses at both ends.
- The Browser still implements a subset of the modern web platform.
