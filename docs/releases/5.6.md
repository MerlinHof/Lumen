# LUMEN 5.6

- The Kindle and emulator share a refresh planner. It weighs change intensity, significant screen coverage and the amount of old ink removed. Small binary updates use DU, ordinary updates use GL16, and broad tonal changes can use GC16 without a clearing flash.
- Study is independently packaged. It uses scoped document requests to open uploaded material in Reader and shared services to start a focus timer and save recall notes.

Both installers contain 37 app packages. The architecture guide lists the 15 remaining linked apps.
