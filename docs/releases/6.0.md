# LUMEN 6.0

- Notes and Settings complete the migration. Both installers ship all 52 active apps as standalone SDK packages.
- The SDK parses incoming JSON structurally and supports nested private storage, scoped Markdown file references, semantic list rows and icon actions.
- The E-Ink planner uses the 5.4 coverage and waveform policy while retaining the current changed-area detection and loading-screen behavior.

Existing Notes, ink, folders and system preferences retain their storage formats.
