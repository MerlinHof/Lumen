# LUMEN 6.8

- News, Recipes, and Store fetch and organize content in their app packages.
  Saved articles, recipes, and catalog preferences carry over. Apps open
  downloaded articles through Reader and import downloaded books into Library.
- News daily editions run using the shared background scheduler. Clock paints
  the alarm screen using the day note supplied by Calendar. The device still
  tracks timer deadlines while Clock is closed.
- Store's bundled catalog and covers, weather icons, and game pieces ship
  with their apps. Settings refreshes Wi-Fi details while its Wi-Fi page is open.
- The build checks that the system links no app code or direct bundled app
  identities. The old app host assembly has been removed.

Physical Kindle testing was skipped.
