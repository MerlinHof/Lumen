# LUMEN 7.2

- Tap feedback uses fast black-and-white refreshes again. The highlight follows
  the painted control and uses a smaller default curve on custom targets.
- Browser has an engraved compass icon and appears after OpenAI in the default
  launcher order. It runs JavaScript through QuickJS in the app's worker,
  including common document edits, click handlers, short timers, and small
  same-origin GET requests. It adapts width rules and simple flex and grid
  columns to Kindle width. Browser APIs and CSS support cover a subset of the web.
- Open a Home Assistant device's history by tapping its card, or use the
  separate power switch. The fullscreen view fetches data for the selected
  range, parses it in a worker, and can display numeric and named states.
- Library has a dedicated Continue Reading card, consistent cover spacing, and
  a shared SDK sort form. Settings and Home Assistant use shared forms, and
  eight games use idle checkpoints with their existing save formats.
