# LUMEN 6.1 · Development status

The Desktop and GitHub source builds target 6.1. The stable update channel
remains on 6.0 while the 6.1 architecture and physical-device checks are pending.

## Changes in the current build

- Notes owns folder creation, rename, moves, deletion and Study recall creation.
  Existing note IDs, folder records, text and ink remain in their original format.
- Study sends recall to a short-lived Notes worker and receives a result. The
  previous Protocol 1 operation name forwards to the same installed worker.
- Settings and six more games use semantic SDK events for standard controls.
- The obsolete linked game and file-browser dispatch and old Settings controls
  have been removed.

## Verified on the Mac

The clean 6.0 source baseline was `da736613013d9c2de087229c034b312b9b587773`.
Native and ARMv7 builds passed. The native suite exercised all 52 standalone
packages, semantic Settings input, Notes folder persistence, long Study
recall through the actual worker, local web exports, installer preservation
and wireless rollback. Both installers carry the same 52 app packages.

| Measurement | 6.0 | 6.1 development build |
| --- | ---: | ---: |
| Stripped ARMv7 core | 25,677,396 B | 25,651,052 B |
| Installed runtime, 150 files | 58,131,677 B | 58,201,609 B |
| USB ZIP | 37.7 MB | 37.8 MB |
| Native Home preview, median | 11.13 ms | 11.07 ms |

The preview starts a new native process and renders Home to a file. Twelve
interleaved runs per version reused seeded synthetic data and warmed filesystem
caches. The timing difference is smaller than the run-to-run variation.
Kindle memory, input latency and refresh timings still require device tests.

## Remaining release checks

- Extract the Notes text and ink session, web export, and legacy storage bridge.
- Move the remaining app-specific provider, archive and alarm behavior out of
  the host. Finish the Settings device API and Reader/Library separation.
- Finish the semantic-control audit of the remaining packages and consolidate
  the overlay lifecycle.
- Test existing user data, installation, rollback, sleep/wake, Wi-Fi, Reader
  formats, keyboard, ink and E-Ink refresh on the Kindle Touch 2. Compare latency,
  CPU, memory and battery behavior with 6.0 on the same device.
