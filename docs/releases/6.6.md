# LUMEN 6.6

- Installed manifests provide app identity and launcher defaults. Navigation
  uses runtime handles and launcher preferences store package IDs. The runtime
  imports prior launcher order and visibility settings.
- Overlay processes come from a shared pool. Status and sleep providers
  supply drawing commands, and the keyboard provider supplies its key
  styling, layout transitions and accents.
- Home Assistant runs its own network jobs and owns its credentials, cached
  data and favorites. File Transfer configuration uses a manifest-declared
  endpoint. Photos owns album membership and slideshow settings.
- Document rendering selects its foreground provider by manifest role.

Remaining host ports include News, Wikipedia, Recipes, Store, document
selection, persistent scheduling and Terminal sessions. The architecture
audit reports direct package references and app implementation imports.
Physical Kindle validation is pending.
