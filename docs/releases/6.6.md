# LUMEN 6.6

- Installed manifests provide app identity and launcher defaults. Navigation
  uses runtime handles and launcher preferences store package IDs. The runtime
  imports prior launcher order and visibility settings.
- Overlay processes come from a shared pool. Status and sleep providers
  supply drawing commands, and the keyboard provider supplies its key
  styling, layout transitions and accents.
- Home Assistant runs its own network jobs and owns its credentials, cached
  data and favorites. File Transfer configuration uses a manifest-declared
  endpoint. Photos owns album membership and slideshow settings.
- Library owns shelf pagination, Continue Reading placement, and its saved
  sort preference. Reader owns its selection menu, tap and swipe preferences,
  and progress display. Both use shared host catalog or document operations and
  are selected by manifest role.
- The native entry point lives under `lumen/system`. Wordle ships its own word
  list. An unused Home Assistant logo and the empty vendor directory were removed.

Host and Kindle builds, package checks, File Transfer, and automated
installer checks passed. Physical Kindle validation is pending.

The broader system audit still reports host dependencies such as News,
Wikipedia, Recipes, Store, scheduling and Terminal sessions.
