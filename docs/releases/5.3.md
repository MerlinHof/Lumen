# LUMEN 5.3

- Journal and Calendar run from independent app packages. They can open legacy journal entries and calendar notes, and save new edits in their own app folders.
- Packages can request the system multiline editor. Calendar uses the shared reading-activity service for monthly reading marks. Clock continues to show the current day’s note when an alarm rings.

The USB and wireless installers contain 33 app packages. The architecture guide lists the 19 remaining linked apps.
