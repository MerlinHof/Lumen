# LUMEN 4.2

## Typography, not imitation segments

The alarm time uses a real serif face rendered directly at its final size. The shared display-type renderer uses MuPDF font outlines, optical glyph bounds and a bounded two-tile cache. It does not enlarge the small UI font or rebuild numerals from shapes. Hour/minute controls align with their respective time groups.

Digital clock faces now use actual typography too. Clock offers fourteen faces, ordered by visual family: Classic Numbers, Classic, Roman, Railway, Minimal, Orbit, Bauhaus, Sundial (24-hour), Compass, Petal Dial, Typography, Editorial, Hour by Hour and Night. Analog designs vary their dial marks, numerals and hand weights deliberately. Existing saved face IDs remain stable. Night fills the whole screen in fullscreen mode.

The shared fullscreen/fit icon has heavier round-capped strokes and curved corner joins, improving its appearance at small sizes throughout LUMEN.

Includes the complete 4.1 update: aligned math and library shelves, anchored note ink, 2D sliding puzzle, continuous Snake, consolidated web navigation and compatible verified GitHub updates.

## Checks and scope

Native/ARM builds, the focused native interaction suite, all fourteen clock faces rendered, native large serif glyphs checked and screenshots inspected. Alarms remain visual interruptions while LUMEN is awake; this update does not add firmware wake scheduling. Apps still share one executable. Wireless updates require matching runtime resources and retain the trial rollback.
