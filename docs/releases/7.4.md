# LUMEN 7.4

- Browser lays out pages on Kindle with litehtml and Gumbo. It renders native
  CSS selectors, media queries, flexbox, typography, borders, and images on
  the E-Ink viewport. Stylesheets are cached across page turns.
- QuickJS runs scripts and HTTP(S) JavaScript modules locally. Pages can read
  browser location and viewport properties and use the supported DOM, form,
  timer, and fetch APIs.
- URL entry and GET forms use the same rules on every website. Ordinary
  single-field forms and search fields can submit from the keyboard.
- Browser supports a subset of CSS and browser APIs. Sites depending on other
  DOM APIs, layout features, or browser services may still exceed that subset.

The Browser package includes the litehtml, Gumbo, stb, QuickJS, and Noto notices.
