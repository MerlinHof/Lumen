# LUMEN 6.5

- All 52 bundled apps now use Protocol 2 manifests with declared surfaces.
  Existing Protocol 1 apps can still launch and retain their private data.
- A package can provide startup, keyboard, status, notifications or the sleep
  screen. Change providers by package ID in `lumen/data/providers.conf`.
- Built-in manifests define compatibility routes. The app registry discovers
  additional packages by ID without requiring changes to the host source.
- SDK 2 adds component click callbacks and dirty-state checkpoints. The
  standalone example uses automatic layout and saves only when its value changes.
- Host and Kindle builds compile independent apps in parallel and reuse
  unchanged objects and app archives. Unused game engines are no longer linked
  into the host.

The runtime still has legacy routes, specialized overlay rendering and
app-specific host services. Existing app state formats remain supported.
Physical Kindle validation is pending.
