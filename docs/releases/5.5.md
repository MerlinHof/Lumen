# LUMEN 5.5

- Home saves the selected app-grid page and restores it when returning from another app. If the catalog shrinks, Home selects the last available page.
- Synchronous loading feedback updates only the busy indicator. The refresh planner skips a second clearing waveform when the previously cleared frame is almost white and the next transition removes little ink. Explicit refresh behavior is retained.
- ToDo runs in its own package and reads existing task records. Measured multiline rows, checkbox, pin and delete actions, and list pagination are available to package clients through the SDK.

Both installers include 36 app packages. Sixteen app views still run inside LUMEN.
