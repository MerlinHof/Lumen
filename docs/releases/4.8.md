# LUMEN 4.8

Home and File Transfer now run from their own native app packages. Their previous linked views were removed. Home owns its artwork, grid, page state and app actions. File Transfer owns its controls and settings. The SDK provides shared app tiles, pagers, package images and QR codes, with asynchronous service replies for catalog and transfer data. The existing server and launcher preferences carry over.

Notifications remains available to other apps and is now hidden in Home by default. You can show it in **Settings → Manage Apps**. Its new icon is an engraved handbell. Existing launchers get the hidden default once, then keep your selection.

This is a checkpoint in the app migration. Library, Reader, Keyboard, Settings and other linked implementations still ship in the runtime.
