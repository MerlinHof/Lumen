# LUMEN 6.1 Preview 1

This preview is available as a manual USB install. The stable OTA channel still serves 6.0. If you install this preview, use USB again for the final 6.1 build because both builds report version 6.1.

- Fixed black rectangles in Calculator, the Clock alarm card, Reading Statistics, and other screens that share the surface renderer.
- Restored the adaptive refresh planner from 5.6. App transitions retain the last frame while a new app starts, and fast transitions can skip the loading hint.
- Added semantic controls in Calculator, Clock, Reading Statistics, Weather, and Reader. Page-turn zones and plot tracing still use position.
- Weather owns geocoding, forecast fetching, and its cache through a temporary package worker. The old host Weather service has been removed.

Native integration checks and startup checks for all 52 app packages passed. Tests cover the affected rendering paths and use simulated forecast responses. Kindle ARM binaries were built locally. Physical panel timing and first launch have not been validated on hardware.

Notes, Reader, Settings, and other apps still depend on app-specific host code. The systemwide semantic-control migration is also in progress.
