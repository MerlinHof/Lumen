# LUMEN 4.7

- System Update takes over the screen as soon as you start the download. It shows the active step in bold and the actual download percentage. The supervisor stays active while installing and reopens LUMEN automatically. Startup shows the same progress screen until the app is ready. The update is confirmed after the first successful screen, so there is no separate Keep button.
- Terminal uses a compact, fixed-width transcript with a hostname prompt immediately after the latest output. The keyboard leaves the recent transcript visible. Hold the prompt to recall a command. Programs such as `ls` can use the terminal width to format their output. The paired File Transfer web terminal uses the same shell implementation and is available whenever File Transfer is running. The code grants shell access, so share it only on a trusted network.
- Notifications is an independently installable app. It owns the banner layout, dismissal and lifetime, and can show a banner over another running app. Open Notifications from Home for a preview.

On 4.6, if **Keep update** is still visible, tap it once to confirm 4.6. Then check for and download 4.7 and use the 4.6 **Restart now** button. If that older launcher exits without returning, open LUMEN once from the Kindle library so the staged installation can finish. The new automatic flow is used for updates started from 4.7.

The package migration remains incomplete. There are fourteen standalone packages, including Notifications. Linked implementations such as Home, Library, Reader, Keyboard and Settings still ship in the runtime.
