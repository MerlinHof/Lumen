# LUMEN 7.3

- Home Assistant discovers a server's same-address HTTPS upgrade without
  forwarding its token to another host. Fullscreen plots keep usable
  cached samples while refreshing and label older data with its date.
- Browser gives the page almost the entire screen. The bottom address bar
  accepts URLs and search terms. Mobile pages can use editable text fields
  and GET forms, including web search. The compass has a white background.
  CSS and JavaScript support cover a subset of browser features.
- Library uses a consistent list with smaller covers and rounded progress
  rings. Continue Reading gets a larger cover and a thicker capsule bar.
  Up to six rows fit on subsequent pages. The renderer prefers smaller
  thumbnails for those rows and keeps more rendered covers in memory.
- Reader lookup shows up to 50 characters before and after each match,
  with a shared pager for mentions up to the current reading page. Compact
  selection menus open near the text and close with an X.
