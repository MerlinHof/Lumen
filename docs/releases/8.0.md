# LUMEN 8.0

- LUMEN fits its portrait layout to the detected display and maps touch to
  the same viewport. Surface API 3 gives bundled apps a shared relative
  geometry protocol and preserves compatibility with existing packages.
- Settings → Hardware keeps screen brightness and Bluetooth radio visible.
  Each control is disabled when the device lacks a usable hardware interface.
- The desktop emulator can boot the same ARM executable and app packages
  shipped in the Kindle release. Change the display preset, resolution,
  or PPI live from the browser toolbar.

The 2014 Kindle Touch 2 remains the supported installation target. The
2026 Kindle Basic and other models are port candidates until their firmware,
touch, display, sleep, and installation have been verified on hardware.
See [Kindle compatibility](../kindle-porting.md) and the
[emulator guide](../../tools/emulator.md).
