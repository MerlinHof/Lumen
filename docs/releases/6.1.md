# LUMEN 6.1

- Notes owns its folder operations and Study recall creation. Existing note IDs,
  text, ink and folder records retain their format. Study opens a temporary Notes
  worker when saving a recall exercise.
- Settings uses named device preferences and semantic controls. The previous
  positional Settings service remains available for Protocol 1 packages.
- Eight games use semantic controls for their toolbars. Frog Solitaire and
  Sliding Puzzle again open their instructions in the shared Reader.
- The SDK adds scoped directory creation, listing and existence checks. The
  document reader uses the foreground package's active data directory, including
  during an update trial. Requests sent in the same burst are handled in order.
- Removed retired linked game, file browser and Settings implementations.

## Validation

Native and ARMv7 builds, startup frames from all 52 apps, USB package
verification, trial rollback, and local File Transfer tests were run on the Mac
with synthetic data. See [validation](../validation.md) for the baseline and
measurements. The physical Kindle pass was skipped at the maintainer's request.
Kindle startup, memory, touch latency, refresh behavior, and battery life remain
unmeasured for this release.

The Notes text and ink session and web export still use the existing host
bridge. Several provider, archive, library and scheduling services still run in
the core. Some packaged apps retain coordinate-based controls, and the overlays
retain separate lifecycle adapters. The [migration inventory](../app-migration.md)
tracks these boundaries.
