# LUMEN 4.1

## Paper tools, better aligned

The calculator now uses a mathematical axis for text, operators, fractions and nested function arguments. The fraction bar and multiplication dot share the same axis. Library's first-page shelf aligns with the lower shelf on subsequent pages. Home labels use one consistent font and a single ellipsized line. Calendar's month controls and content have more vertical breathing room.

Notes translates page ink with the text viewport, including when editing scrolls across a page boundary. Flags share identical filled and outlined geometry. Status app labels use a stable font baseline. Recipes uses a simple botanical food icon.

## Clock and puzzles

Clock has refined counterbalanced hands, reordered faces and two new quiet dials. The alarm has one integrated time-and-enable card, with hour and minute controls. Alarms still require LUMEN to be awake: this does not add firmware wake scheduling.

The 3D sliding game is replaced by a direct 2D fifteen-tile puzzle. The old renderer and its large render/depth buffers are removed. Its stable app ID and saved board are preserved. Snake uses a continuous two-pass body rather than separately shaded cells; its resting overlay no longer covers the snake. Display refresh policy is unchanged. Physical E-Ink head flicker still needs device observation.

## Transfer and updates

Connect has four destinations: Books, Photos, Notes and Apps. Study uploads sit with books; Home Assistant and OpenAI setup sit with apps. The Kindle explanation now covers photos, note exports and app installation.

System now has Update, Storage and Management tabs. Update checks the public GitHub latest release in the background and records the last check. Compatible releases can be downloaded, SHA-256 verified and installed as a trial with rollback. Runtime resources are compared before a binary-only update is allowed. Releases changing scripts, fonts or other required assets need USB. Keep the trial in System or through the web interface; otherwise the previous executable returns on the next launch. The new release includes wireless metadata and an ARM update asset.

Apps remain source modules in one executable. A custom-app installation replaces that executable; it is not an isolated app package and apps cannot yet be independently updated. This release does not claim a plugin ABI.

Sleep timeout lives in Appearance → Sleep screen. Cover padding crop is always enabled; its switch is removed. Independent sleep-screen time and date overlays work across content modes and default to hidden. Routine time synchronization is silent; failures only notify when the last successful sync is older than two days.

## Verification

Native/ARM builds; focused native interaction checks including mathematical-axis rendering and drawing viewport translation; fresh defaults; solvable sliding-puzzle moves; mocked GitHub discovery and refusal of incompatible runtime assets; local HTTP checks. Public screenshots use generated demo content only. Live GitHub download/activation and physical E-Ink behavior still require a device session outside USB mode.
