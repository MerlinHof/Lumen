# LUMEN 8.1

- The wireless updater reports whether a download, checksum, storage check,
  or staging operation failed. Rebuilding unchanged release inputs preserves
  archive checksums.
- QEMU sends changed display rectangles. Scaled previews use filtering,
  while the pixel grid preserves individual pixels.
- Settings combines Wi-Fi and Bluetooth. Appearance brightness and Reader
  font size use a shared slider. Emulator Bluetooth supports a test speaker
  and can connect an explicitly configured, already paired Mac speaker.
- The System Update page offers optional beta updates. Stable remains the default.

See the [emulator guide](../../tools/emulator.md) and
[wireless update guide](../wireless-updates.md).
