# LUMEN 7.7

- Browser runs timeouts, intervals, animation-frame callbacks and microtasks
  within bounded page-load and interaction windows. It orders deferred scripts
  and modules before DOMContentLoaded.
- Browser uses CSS media and feature queries, resolves document base addresses
  and selects responsive picture sources. It reads cascade-layer blocks in
  source order and supports checkbox, radio and disclosure controls.
- Reader highlights matches with up to 25 words on each side and ellipses at
  both ends.
- The web emulator displays frames as soon as they are ready by default and
  coalesces queued pointer motion. Explicit timing flags still preview waveforms.
- Browser still implements a subset of web standards. Long-running background
  scripts, full CSS Grid and video playback are outside this release.
