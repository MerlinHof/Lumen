# LUMEN 7.0

- Reader shows the full sentence around a first mention where possible, adds
  nearby words before and after it, and marks the exact match. The search can
  collect context across page breaks and still runs outside the UI loop.
- The status title and Back indicator are drawn with the current app frame.
  Touch feedback follows the pressed control's corner shape.
- Home Assistant understands compact history responses, prioritizes the opened
  item's graph, and carries the last known value into the visible range.
  OpenAI has a simpler setup, a clearer archive, and a redesigned composer.
- The SDK adds coordinate-free forms with automatic wrapping and paging,
  versioned state with idle, Pause, and exit checkpoints, and explicit HTTP
  results for timeouts, redirect limits, oversize responses, and interrupted
  transfers. Bearer authentication defaults to HTTPS.
- System overlays share hit testing and a cache for decoded actions.
  The keyboard retains its dedicated text-editing and keymap behavior.

Automated validation covers the native runtime, app packages, networking,
ARMv7 build, and installer. Physical Kindle validation is pending.
