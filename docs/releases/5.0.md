# LUMEN 5.0

- Keyboard, Maze, Knight’s Tour and Quotes now ship as independently built apps. The keyboard package supplies key geometry, labels, actions and accent choices. LUMEN composes the surface and handles shared text editing.
- Maze preserves existing boards and trails. Knight’s Tour saves its progress in the app’s private data. Both open their instructions in Reader.
- Quotes queries Reader’s shared annotations and reopens the exact marked position.
- The Protocol 1 SDK adds semantic switches, checkboxes and named actions that can return success, error or cancellation. Existing drawing and input commands remain available.
- Terminal uses larger fixed-width output and recognizes `clear` with surrounding whitespace.

This release ships 21 independent apps. Remaining legacy views still run inside LUMEN.
