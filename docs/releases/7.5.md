# LUMEN 7.5

- Browser follows standard JavaScript navigations and short HTML redirects.
  Scoped cookies are shared between scripts and HTTP requests. Visible
  controls can submit URL-encoded GET and POST forms.
- The local JavaScript engine adds storage objects, Base64 helpers, DOM
  attribute selectors, and form and document APIs. Responsive and lazy
  images use the available source that best fits the Kindle viewport.
- Library progress rings use supersampled edges and rounded caps.
- Browser compatibility remains a subset of HTML, CSS, and web APIs.
  Embedded videos may display a poster image. Video playback is unsupported.
