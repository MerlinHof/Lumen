# LUMEN 7.9

- Wi-Fi shows saved, connected, secured, and open network icons. The selected
  network shows connection progress until the attempt succeeds or fails.
- Library's vertical three-dot menus open at their buttons. Continue Reading
  uses a larger cover with the same proportions.
- Browser adds a Home button and shortcuts to Google, Wikipedia, Standard
  Ebooks, and MDN Web Docs.
- Browser renders SVG images and rounded clipping, handles compound CSS
  feature queries and additional DOM selectors, displays single-choice HTML
  selects, and retains site storage across page navigation.
- Browser still implements a subset of the modern web platform.
