# LUMEN 4.0

## Reliable connections and richer reading

Connect now collects complete headers from a bounded set of sockets before
processing a request. Idle browser preconnections and partially sent headers
cannot monopolize the server. Header deadlines and the inactivity timer use
monotonic time. While the server is enabled, it holds off firmware idle sleep
and restores its owned setting when stopped.

The shared Markdown pipeline now uses the pinned cmark-gfm implementation
already distributed with MuPDF. Horizontal rules, nested lists, tables, task
lists, emphasis, fenced code and other CommonMark features use that parser.
Raw HTML is omitted and unsafe link handling stays disabled.

Reader loading feedback is submitted asynchronously. Small text documents
skip it, and duplicate loading submissions on Reader navigation are removed.

## Small details

Home app labels keep one font size and black ink, with room for two lines.
Home Assistant card titles are quieter. Notes uses the shared list component's
icon placement directly, and Recipes has a clearer dish icon.

The web Appearance tab is removed. The custom-app guide can be used on any
user's computer, with no assumption about a personal Desktop directory.

Photos includes an original portrait pencil sketch, **Alpine Dawn**, at
600 × 800. It is copied to the photo library once and can be selected as the
lock screen. Deleting it is respected.

## Installation and checks

Install over USB because this release adds runtime artwork and a license notice.
The supported target remains Kindle Touch 2, firmware 5.12.2.2, with an existing
compatible jailbreak, .sh launcher and FBInk.

Focused local checks cover HTTP requests alongside idle and incomplete sockets,
CommonMark rules/tables/nesting, and default-photo seeding. Native and ARM builds
are checked. The new server behavior still needs confirmation over the actual
Wi-Fi network.
