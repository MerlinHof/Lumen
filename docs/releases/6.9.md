# LUMEN 6.9

- App buttons, selectors, and switches use named SDK actions. Store,
  Photos, Calendar, Journal, Flashcards, Terminal, Notifications, and
  game controls now use the same input path.
- Indexed actions handle dense views such as all 118 elements in Periodic
  Table and the Chess and Sudoku boards. Ink, graphs, maps, full-screen
  gestures, and irregular playfields retain the spatial input they need.
- The SDK handles HTTPS, authenticated JSON, URL encoding, bounded file
  downloads, and worker cleanup. Network apps and GitHub system updates
  use the shared client.
- The SDK audit checks all 52 bundled packages for direct network
  subprocess calls and raw button routing.

Physical Kindle testing was skipped.
