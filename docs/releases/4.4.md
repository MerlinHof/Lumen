# LUMEN 4.4

Tic Tac Toe now ships as an independent Protocol 1 app package under its existing identity, lumen.tic-tac-toe. Its board, turns, wins, draws and restart remain familiar. Scores and board state are stored in its private data folder. The help action opens the shared Reader. The old Tic Tac Toe view/state/input code is removed from the linked Chess adapter.

This release changes runtime assets by adding the app archive, making it a practical test of 4.3’s complete GitHub updater. No USB installation is performed for this release. On a Kindle already running 4.3, open Settings → System → Update, check, install 4.4, and keep the trial after verifying it. Books and personal state are preserved by the updater.

The reported standalone-app latency and missing explanation buttons in Frog Solitaire/Sliding Puzzle are recorded for the next round and deliberately unchanged here. The extra process/IPC and serialized UI frames are plausible latency contributors; physical timing has not been measured.

Migrating the remaining linked apps is still substantial work; the package framework and full updater do not make the system automatically finished.

Checks: native and ARM builds; Tic Tac Toe win/draw/restart, private state persistence and shared Reader help request; focused existing native/package regression checks.
