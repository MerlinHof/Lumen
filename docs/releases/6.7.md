# LUMEN 6.7

- Wikipedia owns article search, downloads and offline archive management. It
  reads earlier offline archives in place and opens articles via the shared
  Reader interface.
- 2048, Solitaire and Sudoku each compile their own engine. Their rules and
  saved game formats carry over. The SDK now includes common game controls.
- Terminal and File Transfer use the same shell session implementation through
  a shared SDK module. Their existing access controls still apply.
- News now uses one download path. Existing editions remain readable.
- Store can finish a search across multiple providers while another app is open.

News, Recipes, parts of Store and the timer scheduler still have host-owned
behavior. Physical Kindle testing is pending.
