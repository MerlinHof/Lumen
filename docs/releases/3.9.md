# LUMEN 3.9

A calm personal computer for a paper screen.

This release brings the published downloads up to date with the 3.x source.
It includes the illustrated Home, the full engraved icon set, File Transfer
and the app refinements developed since the previous public release, 2.3.

## Home and navigation

Home has a high-contrast alpine illustration, date typography and an initial
eight-app grid. Later pages continue the same ordered list in a full grid.
The bottom navigation bar has been removed. App visibility and order live in
Settings, and all 50 launchable apps have engraved icons. Classic icons remain selectable.

## Fixes and refinements in 3.9

- Snake and Tetris advance by their simulation deadlines. Extra status events
  no longer accelerate either game.
- Wi-Fi status uses the supplicant's connected state, presents changes, and
  retains the last known state when a query is temporarily unavailable.
- Calendar opens on today's date. Calendar, Clock and ToDo use compact segmented
  title bars. Shared lists, forms, icons, pager dots and storage rounding are refined.
- Library cards use more screen space, and Manage Apps fits eight rows per page.
- ToDo edits use the keyboard's attached field. Completed tasks remain visible
  for the current session, and outlined/filled flags show their state.
- Photo rotation rewrites the raster losslessly. Four quarter-turns restore
  the original pixels. A photo's long-press menu can choose it for the lock screen.
- Notes' rich preview uses the shared Markdown Reader, including emphasis.
  Periodic-table properties appear directly beneath the table.
- Home Assistant fits eight dashboard cards per page. Tapping a graph inspects
  a value and timestamp. The OpenAI composer is shorter and its send control is clearer.
- Minesweeper has a clearer board and mines. Hangman keys and Tetris blocks
  use rounded shapes. Snake has a modeled body and apple. Sokoban's reverse
  generator selects less trivial positions, and Maze draws the path taken.

## Custom apps from the web interface

File Transfer's web page has **Install custom apps**. It creates a development
prompt with the live address, pairing code, source/build instructions, shared UI
components, engraved icon guidance, translations and installation endpoints.

An AI agent integrates the app into LUMEN and builds a compatible executable.
The paired web session can stage and install it as a trial. The previous
executable stays available until the trial is kept. Changes to runtime assets,
fonts or launcher scripts require USB.

## Installation and compatibility

- Targeted at **Kindle Touch 2 / 5.12.2.2 / ARMv7 / 600 × 800**.
- Requires an existing compatible jailbreak, .sh launcher and FBInk.
- Install this release over **USB** because it changes runtime assets and
  the update-aware launcher.
- Books, settings, notes and photos are preserved by the installer.
- Approximately **51.8 MiB** installed and **34.2 MiB** downloaded, excluding
  personal data and rollback copies.
- The ZIP checksum is provided as a separate release asset.

## Verification and practical limits

The 3.9 native and ARM builds passed. Focused checks cover UI/default behavior,
game timing, lossless photo rotation, Markdown emphasis, local HTTP pairing,
custom-app staging/approval and the restart handoff. Current gallery images are
native 600 × 800 renders using original demo content.

The runtime was installed on the connected Kindle with all 63 files verified.
The installation check confirmed that the device's books and personal files
were preserved. Physical Wi-Fi behavior, live Home Assistant graphs and the
custom-app restart flow still need on-device use. Native renders do not measure
E-Ink latency. Timers cannot wake deep sleep, calendar data is local, and book
protection/provider compatibility varies.
