# LUMEN 4.9

- Status Bar runs as an independent overlay app package. Notifications remains an independent overlay package and is hidden from Home by default.
- The SDK adds semantic page, button and text input components, structured open intents and helpers for package-owned data. Existing protocol 1 apps remain compatible.
- Built-in launcher artwork is stored with each app and the engraved style is used throughout the launcher. Long app names use the same one-line ellipsis treatment.
- Manage Apps shows versions and removal controls. Essential apps have a disabled removal button.
- Photo transfer preserves supported originals and uses a higher resolution conversion for other inputs.
- Terminal strips display control sequences, supports clearing the transcript and uses larger text.
- The remaining linked apps, including Keyboard, still use the legacy runtime.
