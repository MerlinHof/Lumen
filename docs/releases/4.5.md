# LUMEN 4.5

Install 4.5 over USB on a prepared Kindle to replace the 4.3/4.4 updater. Future compatible GitHub releases can be downloaded from **Settings → System → Update**. The updated screen shows download size, verification, staging and when it is ready to restart. A healthy trial survives a regular restart. A failed startup or interrupted activation still restores the previous runtime. Keep the update to release its rollback copy.

- Terminal runs Linux shell commands and keeps local command history. In the paired File Transfer web page, Terminal requires an additional ten-minute grant via the lock icon in the Kindle app. Commands run with the Kindle shell’s privileges. Access uses local HTTP. Use it only on a trusted network. This version runs individual commands and captures output and exit status.
- 2048 and Sudoku now run as independent packages, with shared system components, Reader help and private saves. Old saves are imported on first use. Frog Solitaire, Sliding Puzzle and Tic Tac Toe remain packaged. Other existing apps still use linked compatibility implementations.
- App processes wake LUMEN when output is available. Idle UI no longer refreshes unchanged status on every tick or periodically resets the Kindle’s inactivity timer.
- Home’s long-press menu can hide an app or remove an installed package. Removal preserves its app data. Linked compatibility apps can be removed from Home, with their implementation still present in the system binary.
- File Transfer notifies the live library of book additions, renames and deletions. The library applies changes when leaving an open book. Covers have a faint gray outline.
- The sleep clock is larger with black numerals and a white outline.

The Kindle still needs a compatible jailbreak and launcher. Preparation depends on the model and firmware. See the [installation guide](../installation.md).
