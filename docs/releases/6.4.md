# LUMEN 6.4

- The runtime retains three paused apps so returning from a related workflow
  resumes the previous view. Notes also saves the open note and page.
- Notes draws from an in-memory surface and batches disk saves. Its ruled
  lines and shared list dividers use lighter gray.
- Reader displays the first matching passage and a Wikipedia extract in a
  context card. Wikipedia owns the on-demand summary operation.
- ToDo supports optional times on deadlines, deadline ordering, and an
  approaching or overdue warning.
- Library moves Continue Reading down and places progress below the author.
  Calculator history uses ten aligned rows. Pressed controls use filled feedback.

Several older app-specific services remain in the host. Physical Kindle
drawing and display performance have not been measured for this build.

Mac and Kindle builds, package checks, File Transfer and installer rollback passed in automated tests.
