# LUMEN 5.4

- Chess runs in an independent package. Its computer opponent computes in the app process. Existing positions are readable, and new saves retain undo history, opponent mode and piece orientation.
- Weather runs in an independent package with the existing forecast service and monochrome icons. Existing locations carry over.
- The SDK exposes shared weather symbols, forecast snapshots and rotated chess silhouettes.

Both installers include 35 app packages. The architecture guide lists the 17 remaining linked apps.
