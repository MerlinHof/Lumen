# LUMEN 6.2 development status

The source targets 6.2. The stable update channel remains on 6.1 while the
architecture criteria and device validation are open.

- Calculator results are right-aligned. The shared editor blinks the caret
  after interaction and then keeps it visible to avoid idle panel refreshes.
- A pending touch highlight survives an outstanding display submission. A
  compact binary mark can use the fast DU waveform without changing the
  redraw policy for normal grayscale content.
- The Kindle backend consumes complete firmware power events and reconciles
  them with the reported device state after power actions or a touch received
  while LUMEN still considers the device asleep. Wake resets the old touch
  gesture and repaints the screen.
- The status bar binds the current view title while composing the same frame.
  The shared selector has a stronger down chevron.
- Library controls and book cards use named SDK actions. Notes owns Markdown
  preview preparation and uses a scoped Reader file intent. Unused shell
  widgets and duplicate source files were removed.
- OpenAI owns its provider, model cache, request and reply files, and uses
  named controls. Its on-demand worker can finish after the user leaves the
  app. Study opens uploaded material through the scoped Reader file intent.

The Notes text and ink editor and web export still use host code. Several
providers and app records still live in the core. Overlay lifecycle adapters
and coordinate-based controls remain in other packages. Full architecture
completion requires those migrations and removal of the old code.

Physical Kindle wake, touch latency, E-Ink behavior and battery use remain
unverified.

## Automated validation

Native and ARMv7 builds, 52 package startup checks, USB package verification,
trial rollback, and local File Transfer tests passed. Synthetic UI tests
exercise caret timing, result alignment, the dropdown chevron, rapid power
transitions and binary refresh selection.

| Measurement | 6.1 | 6.2 development build |
| --- | ---: | ---: |
| Stripped ARMv7 core | 25,499,276 B | 25,502,972 B |
| Installed runtime, 150 files | 58,056,268 B | 58,056,636 B |
| Mac Home startup and first render, median | 12.84 ms | 12.60 ms |
| Mac process peak memory, median | 5,668,864 B | 5,668,864 B |

The native timing is from twelve interleaved runs of each version with warmed
filesystem caches and synthetic data. The small timing difference does not
establish a device speedup.
