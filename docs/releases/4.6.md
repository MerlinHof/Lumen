# LUMEN 4.6

On a Kindle running 4.5, open **Settings → System → Update**. Check for updates, download 4.6, then select **Restart now** when it is ready. Once 4.6 opens and works, choose **Keep update** in the same screen. The release includes a complete wireless runtime and standalone app archives.

- Bingo, Connect Four, Hex, Nonograms, Solitaire, Wordle, and Periodic Table now run as independent native app packages. Their linked implementations were removed. They use the same SDK, installation path, and private app data directories as separately installed apps. Existing game saves are imported where available.
- Terminal now shows a single scrollable transcript, a prompt at the bottom, command history, and a new engraved CRT icon. It keeps a real `/bin/sh` process for the current session, so directory changes and exported variables carry over. Commands have an eight-second deadline. Full-screen terminal programs still need PTY support.
- The Library places the author just below the last visible title line in Continue Reading, using the height of the actual rendered title.

Thirteen apps now ship as independent packages. The remaining linked apps, including Library, Reader, Settings, and Home, still require migration.
