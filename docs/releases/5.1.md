# LUMEN 5.1

- Flashcards, Crossword, Sokoban, Minesweeper, Hangman, Tetris and Snake now run from independent packages.
- Flashcards retains FSRS-6, card editing and review records. The package imports existing cards and schedules. Sokoban and Crossword import their existing boards and progress. Snake imports its previous record.
- Hangman and Crossword use the shared dictionary service. Game instructions open in the shared Reader. Sokoban’s artwork ships in its package and uses the SDK’s sprite renderer.
- Tetris and Snake schedule ticks through the package runtime and pause when LUMEN suspends the app.
- The USB and wireless installers include every independently built app package from the source manifests.

The release contains 28 independently built apps. The remaining 24 linked apps are listed in the architecture guide.
