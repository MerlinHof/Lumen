# Product scope

LUMEN is a local-first, paper-like native shell for the Kindle Touch 2. Its center
is a clean library and a configurable shared reader. Utilities and games should
feel designed for monochrome E-Ink, not copied from a fast color screen.

Core commitments: independent keyboard language; DE/EN/FR UI; shared widgets,
input and app navigation; explicit network actions; preserved personal files;
working return to the original firmware UI; bounded background work and storage.

The detailed design and engineering principles are maintained in
[AGENTS.md](../AGENTS.md). Current capabilities are summarized in the
[README](../README.md); practical limits and evidence belong in
[Validation](validation.md). Old implementation checklists are intentionally not
used as current documentation.
